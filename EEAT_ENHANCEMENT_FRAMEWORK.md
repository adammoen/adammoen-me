# EEAT Enhancement Framework for Blog Articles

## Content Enhancement Checklist

### Experience (Personal Authority)
- [ ] Add specific personal case studies with real companies/situations
- [ ] Include quantifiable results (percentage improvements, client outcomes)
- [ ] Share failure stories that led to insights
- [ ] Mention specific speaking venues, conferences, or partnerships
- [ ] Reference years of experience and number of presentations/clients

### Expertise (Professional Credibility) 
- [ ] Include relevant certifications and credentials
- [ ] Reference peer-reviewed research and studies
- [ ] Cite authoritative sources (Harvard Business Review, Psychology Today, etc.)
- [ ] Link to external authority sites (APA, NAMI, etc.)
- [ ] Demonstrate deep knowledge of subject matter

### Authoritativeness (Industry Recognition)
- [ ] Mention notable clients and speaking engagements
- [ ] Include media mentions and publication features
- [ ] Reference board memberships or advisory roles
- [ ] Show thought leadership through unique frameworks/methodologies
- [ ] Display professional network connections

### Trustworthiness (Credibility Signals)
- [ ] Be transparent about limitations and when to seek professional help
- [ ] Protect privacy through anonymization of client stories
- [ ] Follow ethical standards in content creation
- [ ] Provide accurate, fact-checked information
- [ ] Offer balanced perspectives on complex topics

## Natural Language Enhancement

### Opening Hook Transformation
**Before:** "Mental health in the workplace is an important topic..."
**After:** "Ever wondered why some mental health initiatives fail spectacularly while others transform entire company cultures? After working with 200+ organizations..."

### Conversational Elements to Add
- [ ] Rhetorical questions that engage readers
- [ ] Direct address: "You might be wondering..."  
- [ ] Sentence variety: short impact statements + longer explanatory sentences
- [ ] Personal anecdotes that connect to main points
- [ ] Casual transitions: "Here's the thing..." "So what does this mean?"

### Remove AI-isms
- [ ] Delete: "In conclusion," "Furthermore," "It's important to note"
- [ ] Replace generic phrases: "comprehensive guide" → "step-by-step framework I've developed"
- [ ] Avoid corporate speak: "best practices" → "what actually works"
- [ ] Remove hedge language: "may help" → "has helped my clients"

## Schema Markup Implementation

### Article Schema Template
```json
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "[Article Title]",
  "description": "[Meta description with personal experience reference]",
  "author": {
    "@type": "Person",
    "name": "Adam Moen",
    "url": "https://adammoen.me",
    "jobTitle": "Mental Health Keynote Speaker",
    "worksFor": {
      "@type": "Organization", 
      "name": "Adam Moen Speaking"
    }
  }
}
```

### FAQ Schema for Each Article
- [ ] Include 4-6 frequently asked questions
- [ ] Answer with personal experience and specific advice
- [ ] Use conversational question phrasing people actually search for
- [ ] Provide actionable, detailed answers

### How-To Schema (when applicable)
- [ ] Break down processes into clear steps
- [ ] Include time estimates and difficulty levels
- [ ] Provide tools/resources needed
- [ ] Add success criteria

## Content Quality Control

### Pre-Publication Review
- [ ] Personal experience/case study included in every article
- [ ] Conversational tone with varied sentence structure
- [ ] FAQ section with proper schema markup
- [ ] Internal and external links added strategically
- [ ] Author bio updated with relevant credentials
- [ ] Meta description includes personal experience reference
- [ ] Title optimized for click-through rate + SEO
- [ ] Mobile formatting checked for readability

### AI Detection Management  
- [ ] Run content through AI detector (GPTZero, Originality.ai)
- [ ] If flagged, edit for more natural phrasing and reorder sections
- [ ] Add more personal anecdotes and specific examples
- [ ] Vary sentence structure and paragraph length
- [ ] Include rhetorical questions and conversational elements
